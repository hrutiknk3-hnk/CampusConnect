# CampusConnect — Smart Lost & Found

CampusConnect is a web-based Lost & Found platform designed to help students report lost items, discover found items, and identify possible matches on campus.

## Features
- Report lost and found items
- Search and filter item reports
- View item details
- Find possible matches between reports
- Display dashboard statistics
- Store item reports using SQLite

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open a terminal and navigate to the backend folder.
4. Install the required Python packages if they are not already installed.
5. Start the backend:

   `python -m uvicorn main:app --reload`

6. Open `index.html` using the VS Code Live Server extension.

Backend API documentation: `http://127.0.0.1:8000/docs`

## Project Purpose
This project demonstrates frontend development, backend API integration, database usage, and basic smart matching functionality.
